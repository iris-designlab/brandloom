## 你可以在本机复查

1. 运行 npm test，确认命令行测试通过。
2. 运行 npm run build，双击 index.html。
3. 展开“验证检查器”，运行内置自测；它使用当前浏览器的实际 Canvas 测字。
4. 分别导出 SVG、PNG、项目 JSON 和离线 HTML，再重新打开验证。
5. 用自己的透明 PNG、长译文和不同画幅检查布局。
6. 用真实任务记录人工基线时间和辅助后总时间，不把脚本耗时当成提效比例。
