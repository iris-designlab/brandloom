# 工作流说明

## 输入

品牌规则 + 已确认的三语言文案 + Logo / 产品素材。未上传素材时使用虚构演示图。

## 执行

1. 校验输入完整性与规则范围。
2. 为每个语言和目标尺寸选择内置布局。
3. 放置 Logo 与产品，并保持原始图片宽高比。
4. 根据真实字体宽度换行，在限制内缩小标题字号。
5. 原样保留文案与价格，生成分层 SVG 数据。
6. 执行硬性规则检查。
7. 展示失败项与待人工审核项。
8. 人工调整并选择修正的适用范围。
9. 重新生成并再次审核。
10. 导出图像、项目与检查报告。

## 修正优先级

内置布局 < 尺寸模板偏好 < 当前语言与尺寸修正。

品牌级修正会更新字号上限，所有输出都按新的约束检查；已有手动字号若超出新范围会报错，不会被静默忽略。

重新生成会重置整批视觉确认；纯查看卡片不会重置。

## 文件与职责

- engine.js：纯数据适配与检查，字体测量作为参数注入。
- app.js：表单、Canvas 测字、上传、SVG 渲染、人工反馈与导出。
- index.template.html + styles.css：界面结构与样式。
- build.cjs：把源文件合成一个可离线打开的 HTML。
- tests/：固定测量器下的规则逻辑测试。

## 后续接 AI 的位置

可以在输入阶段建议品牌规则，或在布局阶段提出候选方案；最终仍用检查器验证精确约束。当前仓库没有模型 SDK、API Key 或 AI 调用，也未提供可安装的 Agent Skill。
